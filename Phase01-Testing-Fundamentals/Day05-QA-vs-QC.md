# Day 5: Quality Assurance (QA) vs. Quality Control (QC)

## 1. What Is Quality Assurance (QA)?

Quality Assurance (QA) is a process-focused activity that aims to prevent defects by improving the processes used to develop software.

QA focuses on **how software is developed**.

**Example:**

A QA team creates coding guidelines, defines testing standards, and improves the development process to reduce mistakes.

### QA Activities

- Defining quality standards.
- Improving development and testing processes.
- Reviewing project processes.
- Creating guidelines and procedures.
- Conducting process audits.
- Preventing defects by improving processes.

### Advantages of QA

- Helps prevent defects.
- Improves development processes.
- Promotes consistent quality.
- Reduces rework and costs over time.

## 2. What Is Quality Control (QC)?

Quality Control (QC) is a product-focused activity that checks whether the software meets specified quality requirements.

QC focuses on **the quality of the actual product**.

**Example:**

A tester checks whether a login page accepts valid credentials and displays an appropriate error message for invalid credentials.

### QC Activities

- Executing test cases.
- Identifying and reporting defects.
- Checking actual results against expected results.
- Performing functional testing.
- Retesting fixed defects.
- Performing regression testing.

### Advantages of QC

- Helps identify defects in the software.
- Checks whether requirements are met.
- Improves confidence in the product.
- Helps reduce the risk of defects reaching users.

## 3. Difference Between QA and QC

| Quality Assurance (QA) | Quality Control (QC) |
|---|---|
| Focuses on processes. | Focuses on the product. |
| Aims to prevent defects. | Aims to identify defects. |
| Process-oriented. | Product-oriented. |
| Improves how work is performed. | Checks the quality of the outcome. |
| Includes process reviews and audits. | Includes product testing and inspections. |
| Involves the whole development process. | Focuses on checking deliverables and software quality. |

## 4. Real-Life Example: Login Page

Imagine a company is developing a login page for an online banking application.

### QA Example

The team defines coding standards, reviews development procedures, and establishes testing guidelines to reduce the chances of defects.

This is QA because it improves the process used to build the software.

### QC Example

A tester enters valid and invalid credentials into the login page and checks whether the application behaves as expected.

This is QC because it checks the quality of the developed product.

## 5. Is Software Testing QA or QC?

Software testing is commonly considered a **Quality Control (QC) activity** because it checks the software and helps identify defects.

However, testing is also part of the broader Quality Assurance process in many organizations. QA and QC work together to improve software quality.

## 6. Relationship Between QA and QC

- QA helps improve processes and prevent defects.
- QC checks the product and identifies defects.
- Both contribute to delivering quality software.

**Easy way to remember:**

QA = Prevent defects by improving processes.

QC = Detect defects by checking the product.
