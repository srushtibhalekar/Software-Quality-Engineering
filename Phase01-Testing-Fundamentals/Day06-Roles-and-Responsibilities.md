# Day 6: Roles and Responsibilities in Software Testing

## 1. Introduction

Software testing involves different people working together to improve software quality and identify defects.

Each team member has specific responsibilities during software development and testing.

The main roles include:

- Business Analyst
- Developer
- Software Tester
- QA Engineer
- Test Lead
- Test Manager
- Automation Test Engineer

The exact roles and responsibilities may vary depending on the company and project.

## 2. What Is a Business Analyst?

A Business Analyst (BA) understands business needs and communicates requirements to the development team.

### Responsibilities

- Gather requirements from customers.
- Understand business problems.
- Prepare requirement documents.
- Clarify doubts about requirements.
- Communicate with developers and testers.
- Help define acceptance criteria.

**Example:** A Business Analyst explains that a college management system must allow students to view their attendance.

## 3. What Is a Developer?

A developer designs, writes, and maintains the application code.

### Responsibilities

- Understand requirements.
- Write and review code.
- Develop software features.
- Perform unit testing.
- Fix defects reported by testers.
- Maintain and improve the application.

**Example:** A Java developer creates the student registration feature using Java and a database.

## 4. What Is a Software Tester?

A Software Tester checks whether the application works according to its requirements.

### Responsibilities

- Understand requirements.
- Identify test scenarios.
- Write test cases.
- Prepare test data.
- Execute test cases.
- Compare actual results with expected results.
- Report defects.
- Retest fixed defects.
- Perform regression testing when needed.
- Document testing results.

**Example:** A tester checks whether student registration works with valid details and displays appropriate errors for invalid details.

## 5. What Is a QA Engineer?

A QA Engineer helps ensure software quality through testing, process improvement, and quality practices.

### Responsibilities

- Review requirements and test cases.
- Support quality planning.
- Perform manual or automation testing, depending on the role.
- Identify process improvements.
- Help maintain testing standards.
- Track defects and testing progress.
- Collaborate with developers and other team members.

**Example:** A QA Engineer reviews the testing process and checks whether important requirements are covered by test cases.

## 6. What Is a Test Lead?

A Test Lead coordinates the testing activities of a team.

### Responsibilities

- Assign testing tasks.
- Review test cases.
- Monitor test execution.
- Help resolve testing blockers.
- Track defects and testing progress.
- Coordinate with developers and project stakeholders.
- Share testing status with the team.

**Example:** A Test Lead assigns login testing to one tester and student registration testing to another.

## 7. What Is a Test Manager?

A Test Manager is generally responsible for overall test management and planning across a project or multiple testing teams.

### Responsibilities

- Define the overall testing strategy.
- Estimate testing resources and timelines.
- Manage the testing budget when applicable.
- Monitor risks and quality metrics.
- Coordinate with project stakeholders.
- Report testing status to management.
- Support release decisions with testing information.

**Example:** A Test Manager plans the resources and schedule required to test a college management system before its release.

## 8. What Is an Automation Test Engineer?

An Automation Test Engineer creates and maintains automated tests using programming languages and testing tools.

### Responsibilities

- Identify suitable test cases for automation.
- Write automation scripts.
- Maintain automated test suites.
- Use tools such as Selenium and TestNG.
- Analyse automation results.
- Investigate failed tests.
- Integrate automated tests into CI/CD pipelines when required.

**Example:** An Automation Test Engineer writes Java and Selenium scripts to test the login feature automatically.

## 9. Difference Between Developer and Tester

| Developer | Tester |
|---|---|
| Develops and maintains software. | Checks whether software meets requirements. |
| Writes application code. | Writes and executes test cases. |
| Fixes code defects. | Identifies, documents, and verifies defects. |
| Commonly performs unit testing. | Commonly performs integration, system, and other testing activities. |
| Focuses on implementing features correctly. | Focuses on evaluating software behaviour and quality. |

**Important:** Developers also test their code, and testers may contribute throughout development. Quality is a shared responsibility.

## 10. How the Team Works Together

Imagine a team developing a college management system.

1. The Business Analyst gathers requirements for student registration.
2. The Developer implements the registration feature.
3. The Tester checks valid and invalid registration details.
4. The Developer fixes any confirmed defects.
5. The Tester retests the fixes.
6. The Test Lead monitors testing progress.
7. The Test Manager reviews overall testing status and risks.

Team members communicate throughout the process to deliver reliable software.

## 11. Interview Questions and Answers

### Q1. What does a Software Tester do?

A Software Tester understands requirements, prepares test cases, executes tests, identifies defects, reports them, and verifies fixes.

### Q2. What is the difference between a Developer and a Tester?

A Developer primarily builds and maintains software, while a Tester evaluates the software to identify defects and verify requirements. Both contribute to quality.

### Q3. What is the role of a Business Analyst?

A Business Analyst gathers and clarifies business requirements and communicates them to the project team.

### Q4. What is the role of a QA Engineer?

A QA Engineer helps improve software quality through testing, quality practices, and process improvement. The exact responsibilities depend on the role.

### Q5. What does a Test Lead do?

A Test Lead coordinates testing tasks, reviews test cases, monitors progress, and helps resolve testing blockers.

### Q6. What is the role of a Test Manager?

A Test Manager oversees test planning, resources, schedules, risks, and overall testing progress.

### Q7. What does an Automation Test Engineer do?

An Automation Test Engineer creates and maintains scripts that execute tests automatically using tools and programming languages.

### Q8. Who fixes defects found during testing?

Developers generally investigate and fix code defects. Testers then retest the fixes and check for possible side effects.

### Q9. Is testing only the tester's responsibility?

No. Software quality is a shared responsibility involving developers, testers, business analysts, managers, and other stakeholders.

### Q10. What skills should a fresher Software Tester develop?

A fresher should develop software testing fundamentals, test case writing, defect reporting, SDLC and STLC knowledge, SQL basics, API testing, communication skills, and problem-solving skills.
